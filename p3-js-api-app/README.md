# EventMatch AI

A web app that helps event organizers find suitable suppliers by describing
their event in natural language. Powered by AI for smart, reasoned matches.

## Tech Stack
- Vanilla HTML, CSS, JavaScript
- Google Gemini API (free tier)
- Netlify (deployment + serverless functions)
